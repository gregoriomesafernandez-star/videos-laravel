Videos Laravel

Videos Laravel is a video-sharing web application built with Laravel, Tailwind CSS, Alpine.js, and MySQL.

Users can create an account, log in, upload videos with custom thumbnails, browse content, search for videos, and interact through comments. The platform also includes user profiles, video management features, and a fully responsive design.

Features
User registration and authentication
Video upload and management
Custom video thumbnails
Video search functionality
Comment system
User profiles
Responsive design
Built with Laravel and Tailwind CSS
